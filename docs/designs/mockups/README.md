# Mockups

The author's mockup canvas "Retirement planner screens" (2026-11-19), copied from its claude.ai
artifact on 2026-11-24. Each `.dc.html` file is one screen; `canvas.json` lists them in order.
They are part of the design: see [Screens](../retirement-planner.md#screens), Look and feel.
The files open only in the canvas (they use its runtime); read them as HTML for the markup,
styles and wording. Numbers in them are illustrative.
